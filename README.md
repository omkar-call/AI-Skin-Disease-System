# 🩺 AI Skin Disease Detection System

## 📌 About The Project

AI Skin Disease Detection System is a deep learning-based web application designed to assist in the early identification of skin diseases from dermatoscopic images.

The system uses a trained **EfficientNet-B0 Convolutional Neural Network (CNN)** model with the **HAM10000 dataset** to classify skin lesions into seven different categories. Users can upload a skin image through the web interface, and the system analyzes the image to provide the predicted disease name, confidence score, and associated risk level.

This project combines **Artificial Intelligence, Computer Vision, and Web Development** to create an accessible and efficient solution for preliminary skin lesion analysis.

⚠️ **Disclaimer:** This system is developed for educational and research purposes only. It is not intended to replace professional medical diagnosis or consultation.
